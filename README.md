# Каббала и Таро · Элиора Вейра

Бесплатный вводный курс на GitHub Pages: подробное введение в Тору, Танах, Талмуд и Зоар, 45 уроков, 135 вопросов с пояснениями, интерактивные схемы, 888 коротких фрагментов Зоара: 88 с разборами в 11 темах и 800 для самостоятельного чтения, атлас 78 карт Таро, словарь и личная тетрадь.

## Обновление курса

- Введение в основные книги: `content/books.html`.
- Тексты, задания и источники: `content/course.json`.
- Основной адрес, подпись и дата изменения: `content/site.json`.
- Генератор статических страниц: `tools/build_course.py`.
- Оформление: `assets/course/style.css`; поведение: `app.js`; сохранение и перенос: `state.js`.
- Главная страница сохраняет самостоятельное книжное оформление и встроенную иллюстрацию.

После изменения содержимого:

```sh
python tools/build_course.py
node --check assets/course/app.js
node tests/state.test.cjs
```

Готовые HTML, `course.css`, `robots.txt` и `sitemap.xml` хранятся в репозитории. GitHub Pages публикует корень ветки main. Никакого сервера приложений и внешних JavaScript-библиотек не требуется. Тексты уроков доступны без JavaScript; он нужен для упражнений и тетради.

## SEO и HTTPS

У каждой темы отдельный URL, заголовок, описание, canonical, социальное превью и разметка Schema.org. Карта сайта содержит 66 доступных для индексирования страниц. Тетрадь и страница 404 имеют noindex. Тексты книг целиком не публикуются: используются авторские объяснения, короткие цитаты, библиографические указания и ссылки.

Рабочий адрес — `https://kabbala-tarot.online`. Владелец включил Enforce HTTPS в GitHub Pages и подтвердил работу сайта. Canonical, социальные превью и sitemap используют HTTPS.

Идентификаторы 24 уроков и формат тетради сохранены. Знакомство с книгами доступно перед первым уроком, в основном меню, в словаре и рядом с чтением Зоара. Для нового введения JavaScript не требуется.

Техническая разметка помогает поисковикам обходить и понимать страницы, но не гарантирует позиции или особое оформление результатов. Разметка Course описывает содержимое и не обещает снятую Google функцию Course Info.

Документация: [GitHub Pages HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https), [Google: индексирование JavaScript](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [карты сайта](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).

## Записи и источники

Прогресс и заметки сохраняются только в localStorage данного браузера (`eliora-course-v2`). В тетради есть экспорт JSON для переноса и TXT для чтения; импорт объединяет разные записи, сохраняя существовавший текст. При запрете хранения показывается предупреждение. Автор курса не получает заметки.

Авторская подпись проекта — Элиора Вейра. Личные имя и фамилия на страницах отсутствуют. Биографические заслуги и квалификации не выдумываются. В изложении различаются исторические исследования, религиозные объяснения выбранной традиции и собственные учебные аналогии.


## Расширение: чтение и Таро

- `content/readings88.json`: 88 проверенных коротких цитат, пояснения, вопросы, номер параграфа, страница и SHA-256 использованного PDF. Цитаты сверены с предоставленными файлами, полные современные книги не перепечатываются. Для двух PDF указаны сайт издания и точное имя файла, поскольку действующий прямой адрес не подтверждён.
- `content/tarot.json`: все 78 карт, наблюдения, учебные прочтения и ссылки на изображения и Уэйта. `content/card-images.json` сохраняет адреса изображений, прочитанные из галереи Уэйта–Смит.
- `tools/build_expansion.py`: разделы чтения и Таро. `assets/course/extensions.js`: фильтры карт, сравнение пары и гематрия.
- Заметки и отметки чтения включены в прежний формат тетради версии 2; старые экспорты продолжают работать. Идентификаторы первых 24 уроков сохранены.
- Гематрия использует обычные значения еврейских букв, включая конечные формы; огласовки не считаются. Кириллица и другие алфавиты не преобразуются автоматически.
- Изображения карт загружаются с Wikimedia по HTTPS. Их отсутствие не скрывает описания, вопросы и ссылки на оригиналы.

Проверка: `python tools/check_course.py` и `node tests/state.test.cjs`. Для отдельной сверки цитат можно передать папку исходных PDF скрипту `tools/verify_readings.py` (нужен pdftotext).


## Каталог 888 фрагментов

`/course/reading/catalog/` объединяет прежние 88 цитат и 800 новых коротких фрагментов из 13 предоставленных PDF. Источники, SHA-256, страницы и нумерованные пункты записаны в `content/readings888.json`. В выбранных русских редакциях соседствуют Зоар, Сулам и редакционные пояснения; каталог не атрибутирует все фразы отдельно арамейскому оригиналу.

У 88 прежних записей сохранены текст, идентификаторы, маршруты и авторские разборы. Новые 800 сопровождаются источником и местом для личной записи, без выдуманных пояснений. Каталог поддерживает поиск, 12 тематических фильтров, выбор книги, прочитанные/непрочитанные, записи, ссылки на конкретные фрагменты и показ по 16 карточек. Без JavaScript все цитаты доступны в HTML.

Состояние тетради версии 2 принимает идентификаторы 1–888; импорт прежних тетрадей сохраняет новые записи. Генератор: `tools/build_reading_catalog.py`; интерфейс: `assets/course/reading-catalog.js`. Проверка точных цитат: `python tools/verify_readings888.py PDF_DIRECTORY` (PyMuPDF и pdftotext).
