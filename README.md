# Каббала и Таро · Элиора Вейра

Бесплатный вводный курс на GitHub Pages: 24 урока в шести разделах, 72 вопроса с пояснениями, интерактивные схемы, чтение четырёх отрывков Зоара, словарь и личная тетрадь.

## Обновление курса

- Тексты, задания и источники: `content/course.json`.
- Основной адрес, подпись и дата изменения: `content/site.json`.
- Генератор статических страниц: `tools/build_course.py`.
- Оформление: `assets/course/style.css`; поведение: `app.js`; сохранение и перенос: `state.js`.
- Главная страница сохраняет самостоятельное книжное оформление и встроенную иллюстрацию.

После изменения содержимого:

```sh
python tools/build_course.py
node --check assets/course/app.js
node tests/state.test.cjs
```

Готовые HTML, `course.css`, `robots.txt` и `sitemap.xml` хранятся в репозитории. GitHub Pages публикует корень ветки main. Никакого сервера приложений и внешних JavaScript-библиотек не требуется. Тексты уроков доступны без JavaScript; он нужен для упражнений и тетради.

## SEO и HTTPS

У каждой темы отдельный URL, заголовок, описание, canonical, социальное превью и разметка Schema.org. Карта сайта содержит 30 доступных для индексирования страниц. Тетрадь и страница 404 имеют noindex. Тексты книг целиком не публикуются: используются авторские объяснения, короткие цитаты, библиографические указания и ссылки.

На момент подготовки проверенный рабочий адрес — `http://kabbala-tarot.online`. Переход на HTTPS завершает владелец в Settings → Pages → Enforce HTTPS после готовности сертификата домена. Перед изменением DNS следует проверить сообщение GitHub: не менять записи наугад.

После успешной проверки HTTPS:

1. Сохранить тетрадь в файл на старом HTTP-адресе: браузеры разделяют хранилища HTTP и HTTPS.
2. Включить Enforce HTTPS в Pages и проверить перенаправление HTTP → HTTPS.
3. Изменить `origin` в `content/site.json` на `https://kabbala-tarot.online`, обновить дату и пересобрать страницы.
4. Опубликовать изменения; проверить canonical, sitemap, изображения и шрифты.
5. Подтвердить владение сайтом в Google Search Console и Яндекс Вебмастере, затем отправить `/sitemap.xml`. Способ подтверждения выбирается в аккаунте владельца; чужие или выдуманные коды не добавляются.
6. Импортировать тетрадь на HTTPS-адресе.

Техническая разметка помогает поисковикам обходить и понимать страницы, но не гарантирует позиции или особое оформление результатов. Разметка Course описывает содержимое и не обещает снятую Google функцию Course Info.

Документация: [GitHub Pages HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https), [Google: индексирование JavaScript](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [карты сайта](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).

## Записи и источники

Прогресс и заметки сохраняются только в localStorage данного браузера (`eliora-course-v2`). В тетради есть экспорт JSON для переноса и TXT для чтения; импорт объединяет разные записи, сохраняя существовавший текст. При запрете хранения показывается предупреждение. Автор курса не получает заметки.

Авторская подпись проекта — Элиора Вейра. Личные имя и фамилия на страницах отсутствуют. Биографические заслуги и квалификации не выдумываются. В изложении различаются исторические исследования, религиозные объяснения выбранной традиции и собственные учебные аналогии.
